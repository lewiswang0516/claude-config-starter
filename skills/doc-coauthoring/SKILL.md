# Document Coauthoring

Use the supplied brief, sources, audience, and existing document to draft or revise the requested artifact.
Infer routine structure and wording; ask only for missing facts that materially affect the document.
Do not require the user to select a workflow or approve each section.

## Draft and revise

State the problem, intended outcome, relevant evidence, and unresolved decisions at a level suited to the audience.
Preserve the user's facts, voice, scope, and requested format.
Distinguish supplied facts from assumptions; do not invent evidence, quotations, or decisions.
Use the available document tools when a file artifact is requested.

## Interactive mode

When the user explicitly wants guided coauthoring, gather the missing context and refine the document with their feedback.
Reuse information already supplied and allow them to skip stages.

## Completion

Review the complete document for internal consistency, unsupported claims, missing decisions, and audience comprehension.
Resolve issues that can be fixed from available evidence, then deliver the requested draft or revision.
Report remaining factual gaps without requiring an additional ceremonial review round.
